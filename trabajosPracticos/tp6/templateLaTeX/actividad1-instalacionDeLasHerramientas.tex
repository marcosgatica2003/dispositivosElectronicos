\section{ACT. 1: INSTALACIÓN DE LAS HERRAMIENTAS}
\sangria{} Para el diseño y simulación del inversor CMOS, se necesitaron de las siguientes herramientas \textit{Opensource} compatibles con el PDK SK130: \begin{itemize} \item \textbf{Xschem:} diseño y simulación de esquemáticos. \item \textbf{Ngspice:} modelos spice para la simulación eléctrica en el entorno Xschem. \item \textbf{Magic:} ruteo, layout y verificación del diseño físico (DRC). \item \textbf{Netgen:} comparación LVS (Layout versus Schematic).  \end{itemize}
